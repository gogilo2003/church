# Workspace Guidelines

This workspace uses `AGENTS.md` as the canonical AI agent knowledge base (tech stack, strict rules, knowledge base index, and commit workflow). Consult `AGENTS.md` first; this file is maintained for tooling that reads `GEMINI.md`.

## Version Control & Commits
- **Always Commit Code Changes**: Always remember to commit changes made to the code after implementing features, fixes, or refactoring.
- **Structured Commit Messages**: Use clear conventional commit messages (e.g., `feat:`, `fix:`, `refactor:`, `chore:`).
